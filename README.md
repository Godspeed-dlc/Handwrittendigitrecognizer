# Handwrittendigitrecognizer
# 🧠 Handwritten Digit Recognition using AI

This project is a simple and interactive application that uses a deep learning model to recognize handwritten digits drawn by the user. It combines a trained neural network (on the MNIST dataset) with a Tkinter-based graphical interface to provide real-time digit prediction.

## ✅ Overview

The goal of this project is to demonstrate the power of AI in recognizing handwritten digits using a trained neural network model. Users can draw any digit (0-9) on a virtual canvas, and the model will predict the digit with high accuracy.

---

## ✨ Features

- Deep learning model trained on the MNIST dataset.
- Tkinter GUI for drawing digits.
- Real-time prediction after clicking the **"Predict"** button.
- Uses image preprocessing and normalization for accurate results.

---

## 🛠️ Technologies Used

- **Python**
- **TensorFlow & Keras** – for building and training the model
- **Tkinter** – for GUI
- **Pillow (PIL)** – for image drawing and processing
- **NumPy** – for numerical operations
- **Matplotlib** – for displaying prediction output
